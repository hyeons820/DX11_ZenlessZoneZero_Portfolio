# Zenless Zone Zero - DirectX 11 개인 프로젝트

> C++과 DirectX 11로 제작한 젠레스 존 제로 모작입니다. 맵 편집 도구, 캐릭터 조작과 애니메이션, 전투 판정, 카메라 연출과 툰 셰이딩을 구현했습니다.

## 개요

**Zenless Zone Zero 모작 · 개인 프로젝트**<br/>
**개발 기간:** 확인 후 기입<br/>
**개발 환경:** C++ · DirectX 11 · HLSL · ImGui · FMOD<br/>
**주요 구현:** 에디터 / 애니메이션·캐릭터 조작 / 전투 / 카메라 / 툰 셰이딩 / 레벨 간 상태 유지·사운드<br/>
**전체 시연 영상:** 추후 추가

캐릭터의 조작과 애니메이션을 전투 판정에 연결하고, 제작 과정에서 사용할 편집 도구를 함께 구성한 3D 액션 프로젝트입니다. 이 문서는 최신 원본 프로젝트에서 확인한 구현을 소개합니다. 공개 코드 샘플은 핵심 구조를 발췌한 자료이며, 본문의 추가 구현 중 아직 샘플에 반영하지 않은 범위는 각 절에 표시했습니다.

## 주요 구현

### 1. 맵 편집과 내비게이션 제작

오브젝트 배치와 속성 편집을 위한 도구를 구성했습니다. 편집 요청을 처리하는 `CEditor_Controller`와 엔진 오브젝트에 접근하는 `CEditor_Bridge`를 통해 배치·선택·저장 흐름을 연결합니다.

#### 오브젝트 배치와 마우스 피킹

선택한 프로토타입으로 오브젝트를 생성하고, 선택된 오브젝트의 Transform을 수정합니다. 마우스 좌표와 뷰포트 정보로 레이를 만든 뒤, 편집 레이어의 오브젝트와 교차 여부를 검사합니다. 여러 대상이 겹치면 **교차 거리가 가장 가까운 오브젝트**를 선택합니다.

#### 맵 저장과 로드

편집 레이어의 오브젝트 정보를 수집해 레벨 데이터로 묶고 JSON으로 저장합니다. 불러올 때는 기존 편집 오브젝트를 정리하고 저장 데이터로 다시 생성한 뒤, 선택 상태를 초기화합니다.

#### 내비게이션 셀 제작

입력한 세 점으로 삼각형 셀을 만들고, 유효하지 않은 삼각형을 검사합니다. 기존 정점에 대한 스냅과 정점 방향 정리를 지원하며, 셀들이 공유하는 변을 비교해 이웃 셀 정보를 구성합니다. 제작한 셀 데이터는 파일로 저장합니다.

### 2. 캐릭터 조작과 애니메이션

캐릭터 상태와 애니메이션을 연결하고, 입력 시점과 실제 동작이 자연스럽게 이어지도록 블렌딩·루트 모션·공격 입력 버퍼를 적용했습니다.

#### 애니메이션 블렌딩

현재 애니메이션과 다음 애니메이션의 노드별 로컬 행렬을 구합니다. 이를 위치·회전·크기로 분해한 뒤, 위치와 크기는 선형 보간하고 회전은 **Quaternion Slerp**로 보간해 다시 행렬을 구성합니다. 블렌딩 시간이 끝나면 다음 애니메이션을 현재 애니메이션으로 전환합니다.

#### 루트 모션과 실제 이동

루트 노드의 이전 위치와 현재 위치 차이로 프레임별 이동량을 추출합니다. 캐릭터는 이 로컬 이동량을 자신의 방향에 맞춰 월드 공간으로 변환하고, 이동 보정과 내비게이션 설정을 거쳐 실제 위치에 반영합니다. 루트 노드에서는 수평 이동 성분을 제거해 모델 내부 이동과 오브젝트 이동이 중복되지 않도록 처리합니다.

#### 공격 입력 버퍼와 콤보 연결

공격 중 입력을 일정 시간 보관하고, 현재 공격 상태와 애니메이션 진행률을 검사합니다. 연결 가능한 구간에 들어오면 다음 콤보를 시작하고 버퍼를 비웁니다. 입력 유효 시간이 지나면 버퍼를 해제해 오래된 입력이 뒤늦게 실행되지 않도록 합니다.

#### 차지 스택과 공격 연결

일반 공격 마지막 타격이 적중하면 차지 스택을 지급하고, 같은 공격에서 중복 지급되지 않도록 기록합니다. 차지 공격은 필요한 스택이 있는지 확인한 뒤 상태 전환이 성공했을 때 스택을 소비합니다.

이 흐름은 일반 공격으로 자원을 얻고 차지 공격에 사용하는 전투 순환으로 연결됩니다. 현재 공개한 `Miyabi_Combo.cpp`는 입력 버퍼와 콤보 전환 중심의 이전 발췌본이며, 스택 획득·소비 코드는 아직 포함하지 않았습니다.

### 3. 전투 판정과 패링·저스트 회피

충돌 결과를 몸체·공격·피격·회피·패링 영역으로 구분해 처리합니다. 전투 매니저는 피격 기록과 피해 전달을 담당하고, 캐릭터는 자신의 상태를 기준으로 방어 성공 여부와 후속 동작을 결정합니다.

#### 중복 피격 방지와 다단 히트

**공격자 ID·대상 ID·공격 ID·히트박스 ID**를 기준으로 피격 기록을 관리합니다. 이미 맞은 공격이라면 다단 히트 여부를 확인하고, 최대 타격 횟수와 재타격 간격을 충족했을 때만 다시 피해를 적용합니다. 공격 종료 이벤트를 받으면 해당 공격의 기록을 정리합니다.

#### 피해 계산과 데미지 숫자 표시

공격력과 히트박스의 타격별 피해 배율을 기준으로 피해량을 계산합니다. 플레이어가 몬스터를 공격할 때는 몬스터 등급에 따른 방어 계수와 그로기 상태의 추가 배율을 반영합니다.

피해를 적용한 뒤 대상 ID, 피해량, 피격 위치와 플레이어·몬스터 간 공격 구분을 담은 `EVENT_DAMAGE_TEXT`를 발행합니다. `CDamageTextHUD`는 이 이벤트를 구독해 데미지 숫자 표시를 처리합니다. 피해 판정과 화면 표시를 이벤트로 연결했습니다.

현재 공개한 전투 매니저 샘플은 중복 피격·방어 판정 중심의 이전 발췌본입니다. 최신 피해 계산과 데미지 숫자 이벤트는 아직 샘플에 반영하지 않았습니다.

#### 패링과 저스트 회피

공격 경고 영역과 실제 타격 영역에 대한 패링 처리를 구분합니다. 실제 패링에서는 대상과 공격 정보, 캐릭터 상태를 검사하고 연속 패링 여부에 따라 다음 타격을 기다리거나 반격 가능한 상태로 전환합니다.

저스트 회피는 회피 상태와 중복 발동 여부를 검사합니다. 방어가 성공한 히트박스를 기록해 같은 공격의 일반 피격 처리가 중복 적용되지 않도록 합니다.

#### 시간 배율 제어

플레이어와 몬스터의 시간 배율을 별도로 관리합니다. 패링 충돌 시에는 짧게 시간을 늦추고, 저스트 회피 시에는 두 대상에 서로 다른 지속 시간을 적용합니다. 설정 시간이 지나면 배율을 기본값으로 복구합니다.

### 4. 추적 카메라와 등장·궁극기 연출

일반 플레이에서는 캐릭터가 제공하는 주시점을 보간해 따라가고, 마우스 입력으로 카메라 방향을 조절합니다. 등장과 궁극기에서는 각각의 카메라 애니메이션을 재생한 뒤 일반 추적으로 복귀합니다.

#### 추적과 회전

캐릭터의 주시점과 추적 속도를 이용해 카메라가 바라볼 위치를 보간합니다. 마우스 입력으로 Yaw·Pitch를 갱신하고 Pitch 범위를 제한하며, 회전과 카메라 거리로 최종 위치와 방향을 구성합니다.

#### 카메라 애니메이션 재생

등장·궁극기 연출 시작 시 캐릭터의 월드 행렬을 연출 기준으로 저장합니다. 재생 시간에 해당하는 카메라 키프레임의 위치·회전을 보간하고, 기준 행렬을 적용해 게임 내 카메라 Transform으로 변환합니다. 재생이 끝나면 마지막 카메라 방향에서 Yaw·Pitch를 다시 구하고, 마지막 위치와 시선으로 추적 기준점을 설정한 뒤 일반 추적 모드로 돌아갑니다. 연출 종료 시 카메라 방향을 이어받도록 구성했습니다.

### 5. 툰 셰이딩과 캐릭터 재질

G-buffer에 색상·법선·깊이·재질 정보를 기록하고, 조명 결과와 합성하는 흐름을 구성했습니다. 캐릭터 표현에는 단계형 음영과 MatCap 하이라이트, 얼굴 라이트맵을 적용했습니다.

#### 단계형 음영과 합성

방향광과 법선의 내적 값에 따라 음영을 단계적으로 구분합니다. 최종 합성에서는 기본 색상에 조명을 적용하고 스페큘러와 재질 버퍼의 색상을 더합니다. 얼굴 라이트맵 값은 얼굴 영역의 음영을 보정하는 데 사용합니다.

#### MatCap과 얼굴 라이트맵

뷰 공간 법선으로 MatCap UV를 구하고, 텍스처의 밝기를 이용해 하이라이트를 추출합니다. 얼굴 라이트맵은 샘플링한 값을 부드럽게 변환해 음영 보정에 사용할 값을 계산합니다.

<details>
<summary><b>세부 구현과 관련 코드</b></summary>

- [Renderer.cpp](CodeSamples/Private/05_Rendering/Renderer.cpp): G-buffer 렌더링 → 조명 누적 → 최종 합성.
- [ToonLighting.hlsl](CodeSamples/Private/05_Rendering/ToonLighting.hlsl): 단계형 음영 계산과 재질을 반영한 합성.
- [CharacterMaterial.hlsl](CodeSamples/Private/05_Rendering/CharacterMaterial.hlsl): 법선 처리, MatCap 하이라이트와 얼굴 라이트맵 계산.
- [Renderer.h](CodeSamples/Public/05_Rendering/Renderer.h): 렌더 그룹과 렌더링 단계 선언.

### 6. 레벨 간 상태 유지와 사운드

#### 맵 이동 시 플레이어 상태 유지

레벨을 이동하기 전에 플레이어의 HP, 특수기 게이지, 데시벨, 회피 스택·충전 시간, 차지 스택을 `PLAYER_RUNTIME_DESC`에 담아 `CGameSession_Manager`에 보관합니다. 다음 레벨에서 플레이어를 생성한 뒤 이 값을 복원하고, 현재 값이 최대값을 넘지 않도록 보정합니다.

플레이어 오브젝트가 다시 생성되어도 진행 중인 자원 상태를 이어갑니다. 이 기능은 실행 중 레벨 사이의 상태 전달이며, 게임 종료 후 복원하는 파일 저장 기능과는 구분됩니다.

#### BGM과 행동별 사운드

FMOD를 이용해 BGM과 효과음의 재생·정지·채널 그룹별 볼륨을 관리합니다. 스테이지와 전투 BGM은 도입부를 한 번 재생한 뒤, 재생 종료를 확인해 반복 구간으로 전환합니다.

일반 공격과 피격 상황에서 보이스를 무작위로 선택하고, 차지 공격의 특정 보이스는 지연 시간을 두고 재생합니다. 효과음과 보이스를 캐릭터 행동 흐름에 연결했습니다.

- 원본 `Client/Private/RuntimeLevelLoader.cpp`: 새 레벨의 플레이어 생성 후 상태 복원.

공개 샘플은 최신 원본의 모든 변경을 포함하지 않습니다. 타격별 피해 계산·데미지 숫자 이벤트, 차지 스택, 등장 카메라·복귀 보정, 레벨 간 상태 유지와 사운드 연동은 본문에 설명했으며 샘플 갱신은 별도로 진행할 예정입니다.
